Полностью **автономное нативное мобильное приложение для Android**, работающее **100% локально на смартфоне без подключения к серверу и интернету**.

Вся база данных хранится прямо в памяти устройства (`AsyncStorage`), а все расчеты ресурса, учет ТО и управление гаражом выполняются мгновенно на смартфоне.

---

## 🌟 Ключевые возможности

1. 📊 **Дашборд и «Светофор» ресурса (в реальном времени):**
   * Расчет износа (%) для масла, фильтров, свечей, антифриза, тормозной жидкости и т.д.
   * Цветовые статусы: 🟢 В норме, 🟡 Скоро замена, 🔴 Требуется замена.
   * Показатели пробега, моточасов, средней скорости, общей суммы затрат и стоимости 1 км.
   * Умная защита ввода одометра (подсказка при вводе суточного пробега).

2. 🛠 **Групповой учет ТО:**
   * Добавление и редактирование ТО (ТО-1, ТО-2, ТО-3...) в едином модальном окне.
   * Добавление нескольких замененных деталей в одно событие.
   * Выбор типа цены («за всю канистру / комплект» или «за 1 л / шт»).
   * Автоподсчет итоговой суммы ТО.

3. 📋 **Журнал всех деталей и расходников:**
   * Мгновенный поиск по названиям, маркам (ZIC, VIC, Лукойл, Changan) и артикулам.

4. 🚗 **Гараж и поддержка нескольких автомобилей:**
   * Смена марки, модели, госномера, двигателя, VIN и допуска масла.
   * Добавление нескольких машин и переключение между ними в 1 клик.

5. 🔐 **Безопасность и настройки:**
   * Сессионная защита паролем администратора (по умолчанию: `admin`).
   * Смена пароля администратора в настройках.
   * 💾 Экспорт бэкапа базы данных в JSON через системное меню «Поделиться».

6. 🌓 **Темы оформления:**
   * Переключение между Темной и Светлой темами.

## 🚀 Способы сборки автономного APK

### Способ 1: Автоматическая сборка в GitHub Actions (Бесплатно, без лимитов Expo)
В репозитории настроен готовый GitHub Actions workflow `.github/workflows/build-apk.yml`.
1. Сделайте `git push` в ветку `main` или запустите вручную в разделе **Actions** -> **Build Android APK** -> **Run workflow**.
2. По завершению перейдите во вкладку **Artifacts** и скачайте готовый `app-release.apk`.

---

### Способ 2: Сборка в облаке через Expo EAS
```bash
npm run build:apk
```

---

### Способ 3: Локальная сборка на ПК (Windows / Android Studio)
1. **В 1 клик:** запустите файл `build_apk_local.bat` в папке проекта.
2. **Через консоль:**
   ```bash
   npm run build:apk:local
   ```
